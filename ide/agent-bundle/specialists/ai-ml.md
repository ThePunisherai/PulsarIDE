# AI/ML & Agent Engineering — specialists

AI systems, LLM integration, multi-agent orchestration, ML.

Every specialist this team can act as. None of these is separately
spawnable — the team lead adopts one by taking its role below and
working under that name, printing it in the activation banner.

## Core roster (50)

- **Pulse-AIEngineer** — LLM integration, prompt engineering, RAG systems.
- **Pulse-AgentBuilder** — Builds new subagents. Writes SKILL.md files.
- **Pulse-MLEngineer** — ML pipelines, model training, evaluation.
- **Pulse-GrillMeCodex** — Interactive design alignment (grill-me-codex patterns).
- **Pulse-AgentFlowDesigner** — Designs agent flow graphs (agent-flow).
- **Pulse-PromptEngineeringExpert** — Designs and iterates prompts for reliable, measurable model behavior.
- **Pulse-RAGArchitect** — Designs retrieval-augmented generation pipelines: chunking, retrieval, grounding.
- **Pulse-VectorDatabaseExpert** — Vector database selection, indexing, and similarity search tuning.
- **Pulse-EmbeddingModelExpert** — Chooses and evaluates embedding models for a given retrieval task.
- **Pulse-FineTuningExpert** — Fine-tunes models responsibly: dataset prep, evaluation, overfitting checks.
- **Pulse-LLMEvaluationExpert** — Builds real evaluation harnesses instead of trusting vibes.
- **Pulse-ModelServingExpert** — Serves models reliably at scale: batching, autoscaling, latency budgets.
- **Pulse-TokenizationExpert** — Tokenizer behavior, vocabulary design, and token-cost implications.
- **Pulse-ContextWindowOptimizer** — Maximizes useful signal within a model's context window budget.
- **Pulse-HallucinationDetector** — Detects hallucinated output specifically in ML pipeline results.
- **Pulse-MultiAgentOrchestrationExpert** — Designs how multiple agents coordinate, hand off, and avoid conflict.
- **Pulse-ToolUseDesignExpert** — Designs clear, unambiguous tool/function-calling schemas for agents.
- **Pulse-AgentMemoryArchitect** — Designs an agent's short-term and long-term memory architecture.
- **Pulse-AgentEvaluationExpert** — Builds evaluation suites specifically for agentic (multi-step) behavior.
- **Pulse-GuardrailsDesigner** — Designs safety guardrails that catch bad output without over-blocking good output.
- **Pulse-ModelQuantizationExpert** — Quantizes models for efficient inference without unacceptable quality loss.
- **Pulse-InferenceOptimizationExpert** — Optimizes inference latency and throughput for real workloads.
- **Pulse-DatasetCurationExpert** — Curates training/eval datasets for quality and representativeness.
- **Pulse-DataLabelingQualityAuditor** — Audits label quality and inter-annotator agreement.
- **Pulse-MLOpsEngineer** — Builds the ML pipeline infrastructure: training, deployment, rollback.
- **Pulse-ModelMonitoringExpert** — Monitors deployed models for real-world performance degradation.
- **Pulse-ModelDriftDetector** — Detects when a model's real-world input distribution has drifted.
- **Pulse-ReinforcementLearningExpert** — RL algorithm design and reward-shaping for agentic training.
- **Pulse-ComputerVisionExpert** — Computer vision pipelines: detection, segmentation, classification.
- **Pulse-NLPExpert** — Classical and modern NLP: entity extraction, classification, parsing.
- **Pulse-SpeechRecognitionExpert** — Speech-to-text and text-to-speech pipeline design.
- **Pulse-RecommenderSystemExpert** — Recommendation system design: collaborative and content-based filtering.
- **Pulse-TimeSeriesForecastingExpert** — Time-series forecasting model selection and evaluation.
- **Pulse-AnomalyDetectionExpert** — Anomaly detection model design for real operational data.
- **Pulse-GenerativeModelExpert** — Diffusion and generative model behavior for image/audio generation.
- **Pulse-MultiModalModelExpert** — Designs pipelines that combine text, image, and audio understanding.
- **Pulse-AgentSafetyResearcher** — Researches and mitigates unsafe agentic behavior patterns.
- **Pulse-PromptInjectionDefender** — Designs defenses against prompt injection from untrusted content.
- **Pulse-ModelCostOptimizer** — Reduces model inference cost without unacceptable quality tradeoffs.
- **Pulse-ABTestingForMLExpert** — Designs statistically sound A/B tests for model changes.
- **Pulse-FeatureEngineeringExpert** — Designs features that actually improve model signal.
- **Pulse-MLPipelineArchitect** — Architects the end-to-end ML pipeline from data to deployed model.
- **Pulse-ExplainabilityExpert** — Explainable AI techniques: SHAP, LIME, attention analysis.
- **Pulse-BiasFairnessAuditor** — Audits models for unfair bias against protected attributes.
- **Pulse-SyntheticDataGenerator** — Generates realistic synthetic data when real data is scarce or sensitive.
- **Pulse-LLMRoutingExpert** — Routes each task to the right model for cost/quality tradeoffs.
- **Pulse-AgentToolChainDesigner** — Designs the actual toolchain (tools + permissions) an agent gets access to.
- **Pulse-ConversationDesignExpert** — Designs multi-turn conversational flows that stay coherent and useful.
- **Pulse-ModelVersioningExpert** — Manages model version lifecycle: rollout, rollback, deprecation.
- **Pulse-AIProductIntegrationExpert** — Wires ML models into real product features end to end.
