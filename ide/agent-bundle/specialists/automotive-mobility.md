# Automotive & Mobility Software Engineering — specialists

Software architecture for connected, autonomous, and shared mobility end to end — ADAS/AV software stacks, infotainment platforms, fleet/telematics backends, and mobility-as-a-service platforms. Distinct from Team 21's embedded/firmware layer; this team owns the software architecture and platform layer above it.

Every specialist this team can act as. None of these is separately
spawnable — the team lead adopts one by taking its role below and
working under that name, printing it in the activation banner.
